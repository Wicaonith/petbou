# Courriel de téléchargement

À envoyer à la personne qui prépare l'ordinateur du club. Il ne couvre que le
téléchargement et le premier lancement ; la notice imprimable
(`installation.html`) reprend la même chose en plus détaillé, pour qui préfère
une feuille à côté du clavier.

**Avant d'envoyer**, remplacer le lien ci-dessous par celui de la version
courante : ouvrir <https://gitlab.com/wicaonith/petbou/-/releases>, dérouler les
fichiers de la version la plus récente, et copier l'adresse de
`concours-petanque-portable.zip`. Elle contient le numéro de version, elle
change donc à chaque publication.

**Si vous pouvez apporter le fichier sur une clé USB, faites-le plutôt.** Un
fichier qui arrive par une clé perd la marque « téléchargé depuis Internet », et
l'écran bleu de l'étape 3 n'apparaît pas du tout. Le courriel est le chemin à
distance, la clé est le chemin le plus doux.

---

Objet : Le logiciel de concours — à installer une fois sur le PC du club

Bonjour,

Voici le logiciel pour tenir la table de marque. Il n'y a rien à installer :
c'est un dossier à poser sur l'ordinateur. Comptez cinq minutes.

**1) TÉLÉCHARGER**

Cliquez sur ce lien, le fichier se télécharge tout seul :

<LIEN DE LA VERSION COURANTE>

Vous obtenez un fichier « concours-petanque-portable.zip », dans votre dossier
Téléchargements.

**2) SORTIR LE DOSSIER DU ZIP**

Clic DROIT sur le fichier téléchargé, puis « Extraire tout ».
Vous obtenez un dossier « Concours de petanque ». Posez-le où vous voulez : sur
le Bureau, ou sur une clé USB si le logiciel doit voyager.

Important : ne sortez pas l'exécutable de ce dossier, et ne supprimez pas le
dossier « donnees » qui est à côté. C'est lui qui garde le concours en cours.

**3) LANCER, ET PASSER L'ÉCRAN BLEU**

Double-cliquez sur « Concours de petanque.exe » (l'icône verte).

Au premier lancement, Windows affichera un écran bleu : « Windows a protégé
votre ordinateur ». Ce n'est pas un virus — c'est le message affiché pour tout
logiciel qui ne vient pas d'un gros éditeur.

Cliquez sur « Informations complémentaires » (le petit lien sous le texte), puis
sur le bouton « Exécuter quand même ». Cet écran n'apparaîtra plus ensuite.

**4) METTRE L'ICÔNE SUR LE BUREAU**

C'est le geste qui compte : c'est par là qu'on lancera le logiciel.

Clic DROIT sur « Concours de petanque.exe »
→ « Envoyer vers » → « Bureau (créer un raccourci) »

Sous Windows 11, il faut d'abord cliquer sur « Afficher plus d'options » pour
voir « Envoyer vers ».

**C'EST FINI**

Double-cliquez sur l'icône verte du Bureau : la fenêtre doit s'ouvrir sur
« 1. Réglages ». Dans le logiciel, le bouton « Imprimer le mode d'emploi » sort
une page à laisser près du clavier.

Le jour du concours, le format à choisir est « Tout le monde joue tous les
tours » — c'est le système suisse.

Un fichier LISEZ-MOI se trouve dans le dossier, il redit tout ceci.

Bonne journée,
