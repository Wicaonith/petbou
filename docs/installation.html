Installer « Concours de pétanque »

Cette page s'adresse à la personne qui installe le logiciel, une seule fois, sur l'ordinateur du club. Comptez cinq minutes. Ensuite, tenir la table de marque ne demande plus rien de particulier : il y a un mode d'emploi séparé pour ça.
Le plus simple : apportez le fichier sur une clé USB

Téléchargez l'installeur sur votre propre ordinateur, copiez-le sur une clé USB ordinaire, puis branchez la clé sur le PC du club. Windows n'affichera alors aucun avertissement, parce qu'un fichier qui arrive par une clé n'est plus marqué comme venant d'Internet. Vous pouvez sauter l'étape 2.

  1. Récupérer le fichier

    Sur GitLab, ouvrez le projet, puis le menu Build → Pipelines, et téléchargez l'artefact du dernier pipeline vert. Le fichier s'appelle quelque chose comme Concours de pétanque_0.1.0_x64-setup.exe.

  2. Si Windows affiche un avertissement bleu

    Cela arrive quand le fichier a été téléchargé directement sur ce PC. Ce n'est pas un virus : Windows signale simplement que l'éditeur du logiciel n'a pas payé de certificat de signature. Voici l'écran, et ce qu'il faut cliquer :

    Windows a protégé votre ordinateur
    Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue.

    → Cliquez sur Informations complémentaires (le petit lien, facile à rater)
    → Puis sur le bouton Exécuter quand même qui apparaît en bas
  3. Dérouler l'installation

    Cliquez Suivant jusqu'au bout. Aucun mot de passe administrateur n'est demandé : le logiciel s'installe pour l'utilisateur courant. Sur le dernier écran, cochez « Créer un raccourci sur le Bureau » — c'est par là que la personne qui tient la table lancera le logiciel.

  4. Vérifier que ça marche

    Fermez tout, puis double-cliquez sur l'icône verte du Bureau. La fenêtre doit s'ouvrir sur l'écran 1. Réglages, avec un bandeau vert en haut. C'est bon.

  5. Laisser le mode d'emploi à côté du clavier

    Dans le logiciel, onglet 1. Réglages, bouton Imprimer le mode d'emploi. Une page, à poser près de l'ordinateur.

Si la fenêtre ne s'ouvre pas du tout

Le logiciel a besoin de Microsoft Edge WebView2, présent d'office sur Windows 11 et sur la quasi-totalité des Windows 10. S'il manque sur un poste ancien, l'installeur sait le récupérer si l'ordinateur a Internet. Sinon, téléchargez « WebView2 Runtime » sur le site de Microsoft, sur votre ordinateur, et apportez-le sur la même clé USB.

Vous préférez ne rien installer ?

Le pipeline produit aussi concours-petanque-portable.zip. Décompressez-le sur une clé USB et lancez l'exécutable : rien ne s'installe, et le concours en cours reste sur la clé. Gardez le dossier donnees à côté de l'exécutable. Cette solution est pratique pour vous, mais un raccourci sur le Bureau reste plus simple pour la personne qui tient la table.

Ce que verra ensuite la personne qui tient la table : un bandeau vert, en haut de l'écran, qui lui indique à chaque instant la seule chose à faire. Elle n'a rien d'autre à retenir.
