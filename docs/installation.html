Mettre « Concours de pétanque » sur l'ordinateur du club

Cette page s'adresse à la personne qui prépare l'ordinateur, une seule fois. Comptez cinq minutes. Il n'y a rien à installer. Ensuite, tenir la table de marque ne demande plus rien de particulier : il y a un mode d'emploi séparé pour ça.
  1. Récupérer le fichier, sur VOTRE ordinateur

    Ouvrez github.com/Wicaonith/petbou/releases/latest et prenez la version la plus récente, en haut. Dans les fichiers proposés, téléchargez concours-petanque-portable.zip. Cette adresse ne change jamais, et les fichiers y restent : c'est elle qu'on redonne à chaque nouvelle version.

  2. Le copier sur une clé USB

    N'importe quelle clé fait l'affaire. Ne la branchez pas encore sur le PC du club.

    Ce détour n'est pas une perte de temps

    Windows marque les fichiers venus d'Internet et affiche un écran bleu inquiétant au premier lancement. Une clé USB efface cette marque : le logiciel démarrera sans aucun avertissement.

  3. Sortir le dossier du zip

    Branchez la clé sur le PC du club. Clic droit sur le zip → Extraire tout. Vous obtenez un dossier Concours de pétanque contenant l'exécutable, un dossier donnees et un LISEZ-MOI. Posez ce dossier où vous voulez : sur le disque du PC, ou laissez-le sur la clé si le logiciel doit voyager.

  4. Créer l'icône sur le Bureau

    C'est le geste qui compte, c'est par là que la personne lancera le logiciel.

    Clic droit sur Concours de petanque.exe
    → Envoyer vers → Bureau (créer un raccourci)

    Sous Windows 11, cliquez d'abord sur Afficher plus d'options pour voir Envoyer vers.
  5. Vérifier, puis imprimer le mode d'emploi

    Double-cliquez sur l'icône verte du Bureau : la fenêtre doit s'ouvrir sur l'écran 1. Réglages, avec un bandeau vert en haut. Puis, dans le logiciel : Imprimer le mode d'emploi. Une page, à poser près du clavier.

Deux choses à ne pas faire

Ne sortez pas l'exécutable de son dossier, et ne supprimez pas le dossier donnees : c'est lui qui garde le concours en cours. Si le logiciel est resté sur la clé USB, le raccourci du Bureau ne fonctionnera que quand la clé est branchée.

Si un écran bleu « Windows a protégé votre ordinateur » apparaît

C'est que le fichier n'est pas passé par une clé USB. Ce n'est pas un virus : Windows signale que l'éditeur n'a pas payé de certificat. Cliquez sur Informations complémentaires — un petit lien facile à rater — puis sur Exécuter quand même.

Si la fenêtre ne s'ouvre pas du tout

Le logiciel a besoin de Microsoft Edge WebView2, présent d'office sur Windows 11 et sur la quasi-totalité des Windows 10. S'il manque sur un poste ancien, la version portable ne peut pas l'ajouter : prenez alors le fichier …-setup.exe du même pipeline, qui sait le récupérer tout seul.

Ensuite, la personne qui tient la table double-clique sur l'icône verte et se laisse guider par le bandeau vert. Elle n'a rien d'autre à retenir.
